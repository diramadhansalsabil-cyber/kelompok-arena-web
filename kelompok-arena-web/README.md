## Cara menjalankan di HP / browser

1. Buka folder ini di File Explorer.
2. Double-click `index.html`, **atau**
3. Jalankan server lokal (opsional):

```bash
npx --yes serve .
```

Lalu buka alamat yang muncul di browser HP (satu Wi‑Fi dengan komputer).
